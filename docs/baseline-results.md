# Baseline Results (120-run Tier)

This chapter is the complete evidence dump for the only post-fix empirical tier that exists today: the single-agent baseline runs. It documents what the tier is, exactly how it was produced, the full numeric results, and the interpretive guardrails that must survive into the paper. All facts come from the run artifacts in `runs/baselines/` and the analysis files in `reports/baselines/` generated by `scripts/analyze_baselines.py`.

## Tier definition and eligibility

The baseline tier consists of 120 runs: three environments (resource foraging, bargaining game, number guessing) × four memory policies (`no_memory`, `naive_overwrite`, `raw_trajectory_buffer`, `structured_incremental`) × ten seeds (40 through 49 inclusive). Every run is single-agent in the sense of having no communication: sharing mode is `off` in every baseline config, so the metadata `topology` field reads `full_broadcast` only because of the schema default, but the effective topology — the value every analysis script actually uses — is `off`. Poisoning is `clean` throughout; the fraction being controlled is therefore the 0-contamination check) and the poisoning fields are all 0. The model is `qwen2.5:7b` on the local Ollama server, decoding is deterministic (`temperature: 0`, `seed: null`, `max_tokens: 512`, `top_p: 1.0`), there are six agents per environment, and episode length is 50 rounds for every environment including number guessing (which may end earlier when the secret is found). Each run folder carries a `metadata.json`, `config_snapshot.yaml`, `events.jsonl`, and `summary.json`, and the sweep was produced by the fixed post-audit code, so the tier is audit-eligible: clean runs show 0 peer contamination, the invariants pass, and `summary.json` exists for all 120 conditions.

The raw numbers below are reproduced from `reports/baselines/summary_statistics.csv` and `reports/baselines/summary_table.md` (which are in turn recomputed from the run folders by `analyze_baselines.py` — the CSV and Markdown are derived outputs, not sources). Every mean is over 10 runs unless noted; every confidence interval is a two-sided 95% Student-t interval on the mean, clipped to `[0, 1]` for the bounded metrics.

## Reading the tiers environment by environment

**Resource foraging** is where the structured policy is unambiguous. Its score (0.4767, CI 0.4595–0.4938) is approximately four-fold higher than the `no_memory` control (0.1129) and more than seven-fold higher than either the naive or raw policies (0.0650 and 0.0618), with intervals that do not overlap any other condition. Under the per-seed headroom normalization its efficacy gap is 1.53, i.e. the playbook-driven agent surpasses the deterministic greedy oracle (0.3789) by roughly one and a half times the recoverable gap — a striking and legitimate result rather than a measurement artifact, since the oracle, moving greedily toward the nearest visible resource, is itself suboptimal and the structured agent can encode longer-horizon harvest sequences. Self-BLEU for all three text-emitting policies is at ceiling (≈1.0) while `no_memory` sits at exactly 0.0, which means the collapse measure in this environment is near-saturated and separates "any memory at all" from "no memory" rather than discriminating policy quality.

**Bargaining** shows the opposite and sobering pattern. Every policy scores far below the oracle 1.0, and the structured policy's modest 0.0590 is the best of the three text policies and statistically above naive overwrite (0.0020, FDR p = 0.0011, Cliff's δ = 1.0) but not above `no_memory` (0.0455, FDR p = 1.0). Raw trajectory buffer scores exactly 0.0000 with zero variance across all ten seeds — it is significantly *worse* than no memory (FDR p = 0.0491): replaying a verbatim conversation history without abstraction actively prevents deal-making. The environment's scores are dominated by accept/reject dynamics that a text policy apparently cannot stabilize, and because the oracle accepts everything, fairness numerators hover near zero while the oracle's remains at 1.0.

**Number guessing** is the coordination-speed env with the narrowest score spreads. Nobody reliably beats the no-memory control: raw buffer is numerically highest (0.0722) and structured slightly negative on the gap scale (-0.1233), but no pairwise comparison reaches significance after FDR — including the n=8 efficacy-gap tests, where two seeds were dropped because their `no_memory` mean score exactly matched the oracle, collapsing the headroom to zero. The interesting observation in this environment is Self-BLEU: structured (0.9867) and raw (0.9875) remain near-ceiling, but naive overwrite drops to 0.0725, meaning the LLM-refreshed naive memory produces lexically variable reflections across rounds here — a useful caveat demonstrating that Self-BLEU is not a constant property of a policy but interacts with the observations it is reflecting on.

## Oracle reference scores

The oracle sweeps a deterministic policy on the same `(env_type, seed)` instance and is therefore reproducible per seed. Foraging oracle mean 0.3789 (SD 0.0831); guessing oracle mean 0.1581 (SD 0.0189); bargaining oracle fixed at 1.0. The oracle plays greedy-nearest-harvest, binary search, and accept-every-50/50 respectively; do not present these as absolute ceilings — the structured foraging run exceeds its own oracle, and the bargaining oracle is trivially maximal only because the accept-all policy always closes a deal.

## Statistical highlights

The inferential layer for this tier lives in [statistical-analysis](statistical-analysis.md); only the headline findings are repeated here. Three genuinely significant results survive FDR: structured beats no memory on foraging score, structured beats naive on foraging score, and structured beats all others on the foraging efficacy gap (raw p ≈ 1.7e-4–6.3e-4, all FDR p = 0.0011, Cliff's δ = 1.0 / 1.0 / 0.98). Raw buffer losing to no memory on bargaining score is significant with a large negative effect (FDR p = 0.0491). Everything else — the entire number-guessing tier and most of bargaining — is statistically indistinguishable at n = 10.

## Relationship to the other tiers

This tier is not the full experiment; the factorial tier (policies × topologies × poisoning modes across seeds, planned at 540 runs when it includes the four-policy list at ten seeds) has not been executed yet — there is no `runs/experiments` output as of this writing. Everything in this chapter is therefore about isolated, clean, single-agent behaviour only, and the sharing and poisoning questions raised in [sharing-and-poisoning](sharing-and-poisoning.md) and the H4/H5 hypotheses in [statistical-analysis](statistical-analysis.md) await that tier. Finally, do not compare these numbers with the pre-fix figures in `literature/project_scope/paper_summary.md` (which summarises much older runs and is explicitly non-citable); the audit-history chapter details why.
