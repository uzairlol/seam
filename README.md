# SEAM

Shared Evolving Agent Memory.

This repository is intentionally minimal. It exists as the public shell for the shared self-evolving memory project, while the literature and working materials remain ignored locally.

## What is here

- A compact project identity for the research effort.
- An ignore policy that keeps the literature folder and other working files out of the public repo.

## Working assumption

The actual implementation, experiments, and notes are developed locally and are not committed to this repository until explicitly unignored.
